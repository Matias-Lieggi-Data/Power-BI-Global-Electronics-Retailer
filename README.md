# Power BI — Global Electronics Retailer

## 📊 Project Overview

Interactive Power BI dashboard developed to analyze sales performance, profitability, customer behavior and order activity for a global electronics retailer.

The project focuses on transforming raw data into useful business insights through data cleaning, data modeling, DAX calculations and interactive visualizations.

## 🎯 Objectives

- Analyze overall sales and profitability.
- Identify sales trends and key performance indicators.
- Understand customer behavior.
- Analyze product and category performance.
- Build an interactive dashboard to support data-driven decision-making.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel

## 🔄 Data Preparation

The project included:

- Data cleaning and transformation.
- Data type standardization.
- Data organization and preparation.
- Data modeling.
- Creation of calculated measures using DAX.

## 📈 Key Performance Indicators

- Total Sales
- Gross Margin
- Units Sold
- Unique Customers
- Number of Orders
